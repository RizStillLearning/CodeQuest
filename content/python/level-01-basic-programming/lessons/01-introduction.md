## Coba ini

```python
print("Halo, CodeQuest!")
print("Saya sedang belajar Python.")
```

Output:

```
Halo, CodeQuest!
Saya sedang belajar Python.
```

## Apa yang terjadi?

**Program** adalah daftar perintah untuk komputer. Python menjalankannya
**satu per satu, dari atas ke bawah**.

`print()` menampilkan sesuatu di layar. Apa pun yang kamu tulis di dalam tanda kurung
akan ditampilkan, dan setiap `print()` dimulai di baris baru.

Teks harus diapit tanda kutip: `"Halo"`. Tanpa tanda kutip, Python mengira kamu
menyebut nama sesuatu, bukan teks.

## Komentar

Baris yang diawali `#` adalah **komentar**. Python melewatinya: komentar adalah catatan untuk manusia.

```python
# Baris ini dilewati
print("Baris ini dijalankan")
```

Output:

```
Baris ini dijalankan
```

## Ingat

- Program berjalan dari atas ke bawah, satu baris setiap kali.
- `print()` menampilkan output di layar.
- Teks ditulis di dalam tanda kutip.
- `#` mengawali komentar.
